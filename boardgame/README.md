# Board-game room (Three.js + sand3d)

Three square play tables, four matching chairs facing inward, procedural boards on tabletops. No restaurant booths.

## Open
```bash
cd boardgame
python3 -m http.server 8772 --bind 127.0.0.1
```
`T` toon · `U` unlit · `?mode=unlit` · `?cam=corner` · `?cam=close`
