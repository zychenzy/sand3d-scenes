# Gaps

- No microphone GLB worth using. Handhelds and the stand are procedural, so the grille is a stack of rings rather than a mesh.
- The shared TV is a small floor-stand display with its broad face in the YZ plane. It is the queue monitor on the credenza. The main screen is a framed plane so the picture faces the sofas. A lyric texture is drawn in canvas; it is not a video.
- The shared speaker is a small portable box. Scaled up and set on plinths it reads as a monitor, not a full-range cabinet. The driver is the flat face, not a modelled cone.
- The long sofa is the loveseat asset scaled on X (about 1.78). Arms and cushions stretch with it. A true four-seat GLB would be cleaner.
- Contact grounding is a dark disc plus the key light’s hard shadow map. There is no SSAO.
- The shell is a cutaway: no front wall, and no full right wall. The pier only closes the screen corner.
- Pendant bulbs and the cove are emissive meshes. Toon shading still bands the shades; unlit mode keeps the glow by using the emissive color.
