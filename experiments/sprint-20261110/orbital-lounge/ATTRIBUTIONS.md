# Attributions

This scene does not instance furniture GLBs. Benches, the pedestal table, lockers, the galley niche, the hull, and the port view are procedural meshes written for this folder.

The page imports the existing lounge vendor build (`/lounge/vendor/three.module.js`, Three.js r170, MIT), plus OrbitControls and GLTFLoader from `/lounge/vendor/`.

Reference photographs are linked, not copied, in `refs/SOURCES.md`.
