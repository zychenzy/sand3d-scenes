# North Pins bowling alley

Four-lane house alley, cut away on the concourse side. Lanes 7–10 run toward −Z. Approaches, gutters, ball returns, scoring consoles, masking, settees, a snack counter, a shoe desk, and a ball rack are in the same room.

Serve from the repo root so the vendor and asset symlinks resolve:

```bash
python3 -m http.server 8791 --bind 127.0.0.1
```

Open `http://127.0.0.1:8791/experiments/indoor-20261113/bowling-alley/`.

- **T** toon (default): `MeshToonMaterial`, 4-step gradient, hard shadows.
- **U** unlit: `MeshBasicMaterial`.
- `?mode=unlit`, `?cam=corner`, `?cam=close`, `?hud=0`.

`layout.json` is generated by `tests/geometry.py`. Do not hand-edit it.

```bash
python3 experiments/indoor-20261113/bowling-alley/tests/geometry.py
python3 experiments/indoor-20261113/bowling-alley/tests/check_layout.py
```

Lane beds are a real 1.08 m wide. Foul-to-head is about 11 m, shorter than a full 18.29 m lane, so the approach and the pin deck share one frame. See `refs/GAP.md`.
