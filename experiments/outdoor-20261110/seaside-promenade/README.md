# Seaside promenade

A small coastal walk: curving stone seawall, tiered steps down to the beach, a timber viewing pocket, benches facing the water, a bicycle stand, and a gelato kiosk. Bright daytime, Toon hard by default.

## Run from the repo root

Relative assets (vendored Three.js and the linked GLBs) resolve from the repository root:

```bash
python3 experiments/outdoor-20261110/seaside-promenade/test_layout.py
python3 -m http.server 8791 --bind 127.0.0.1
```

- http://127.0.0.1:8791/experiments/outdoor-20261110/seaside-promenade/
- `?cam=corner` from the water, looking back at the steps and the kiosk
- `?cam=close` on the tiers, from the sand
- `?mode=unlit` flat colours
- Keys `T` and `U`, or the buttons, switch shading. Drag to orbit.

## Layout

`layout.json` is generated by `layout_model.py`. The test checks that the file matches the model and that benches face the water, the kiosk counter faces the sea, the steps meet the sand, the shore actually curves, and the through path stays clear.
