# Library reading room (Three.js + sand3d)

Reading room: wall stacks filled with books, two long communal tables, chairs facing the tables/stacks, banker lamps, catalog lectern zone.

## Open
```bash
cd library
python3 -m http.server 8770 --bind 127.0.0.1
```
`T` toon · `U` unlit · `?mode=unlit` · `?cam=corner` · `?cam=close`
